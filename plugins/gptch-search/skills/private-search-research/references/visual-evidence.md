# 可选视觉取证工具

只在画面能填补证据缺口时调用。先筛选视频，再决定少量预览、明确时间点或局部细化；不是每次研究的必经流程。工具提供客观线索，由模型决定语义关键帧和停止条件，不运行OCR、参数分类器或价值总分。

- `inspect_video(request)`：content_id为BV或保留p参数的URL。timestamps为原视频秒数，最多6个；不传则preview_count（默认4，最多6）均匀稀疏预览。profile=preview选择最低分辨率，detail在当前访问条件下选择不高于720p；不是购买或绕过高清访问权限。
- `region=[x0,y0,x1,y1]` 可从已观察画面选归一化区域裁图；底层全帧差异线索仍标明full_frame。原素材低分辨率或已剪裁的内容不会因此恢复细节。
- 返回首个文本块为归属及时间元数据，后续MCP image/png块依frames顺序对应。记录BV/aid/CID/分P、请求与实际帧时间、提取时间、分辨率、处理方式和sha256。以actual_seconds引用，不把请求时间当作绝对准确的帧时间。
- `read_video_evidence(evidence_id)` 只读保留的元数据与图片，无平台请求。不接收任意本机路径。图片缓存7天、共享磁盘目标128MB，可能提前淘汰；过期明确报错。分段缓存24小时，并按身份及内容索引指纹复用；不是永久媒体档案。

可根据字幕/章节线索定位，也可以先看少量代表帧再选某段t-2、t、t+2等。密度由问题决定，没有固定截图间隔。长静态软件界面的小范围参数变化不应只用场景切换判定；global pixel diff、4×4局部变化和边缘/灰度线索仅帮助观察，不证明语义变化或可信度。界面缩放、鼠标、转场也会造成差异；重复比较像素不应代替参数辨认。

媒体只支持平台在当前会话提供的非DRM AVC DASH SegmentBase/sidx及准确HTTP Range。一次调用默认媒体16MB（上限32MB）、HTTP20（上限40）、最多6帧，单分段8MB、总图片8MB；一项调用/解码同时进行。120秒总限时、单帧解码25秒，失败清理临时文件。需要本机FFmpeg；没有运行时或格式不支持时明确失败，不改为完整下载。HTTP403/412/429停止，不高频重试/轮换代理。已有采集工作进程运行时先等其结束。

MCP标准图片块是首选。当前开发验收已验证真实stdio图片负载、逐图哈希以及Codex本机图片读取桥接后的实际视觉分析；**不代表Work原生MCP图片渲染已验**。若客户端确实没有把图片送给模型，可在同一本地执行环境使用frames.local_image_path对应的图片读取工具，核对sha256；跨主机本机路径不保证可读。没有可用图片读取方式就说明限制，不能把“返回图片”写成“已看过”。

目前没有音频截取、试听、波形、频谱或ASR工具，相关能力报告为false；不因视频已取帧而声称听到音效或完成控制实验。对重要画面声明仍沿用证据权重原则，推广横幅可直接观察，但不能据此断言付费赞助；看见操作也不证明收益/性能。
