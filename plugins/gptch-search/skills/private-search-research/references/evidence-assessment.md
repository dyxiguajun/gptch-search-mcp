# 影响结论时的证据判断

本说明用于关键声明、明显商业利益或相互冲突的证据；由模型选择核实力度和来源，不要求逐视频审计、固定流程、最低来源数量或数值可信度评分。相关性、可信度和独特性分开判断。

## 声明与来源分别看

相关性回答“是否解决当前问题”；可信度回答“这项具体声明在何种条件下有何依据”；独特性回答“是否带来已有材料之外的信息”。相关的营销内容可能包含可验证技术细节；低热度反例可能独特但仍待复现；十次转载增加曝光，不增加独立证据。没有必要为这三项强制生成标签或分数。

对曝光偏差保持敏感：原生搜索/推荐顺序、当前可见评论、热门截断和自己的检索词都会影响样本。热门排序不是代表性抽样，未找到反例不是不存在反例。重要决策可按缺口改词、查看适用版本或反面经验；无需穷举不同立场或为平衡数量给弱证据相同权重。

## 利益关系及独立验证

- 保留已观察到的赞助披露、带货/佣金链接、作者与产品的明确关系、夸张承诺及其出处。只将广告关键词或推销语气作为线索，不据此断言收钱、欺骗或内容不可信；没有披露也不能证明无利益关系。无需收集额外个人账号资料。
- 将“厂商声称”“演示里观察到”“独立测试支持”“本次未复现”区分开。官方规格/版本说明适合核对设计与支持范围；跨产品性能、实际效果或收益承诺更需要检查测试条件、可复现步骤和独立结果。独立来源也可能有方法缺陷，来源类别不构成固定权重表。
- 识别转载、编译、共享新闻稿/图表/脚本、同一原始测试或共同引用。多家文章引用厂商同一张图仍属同一个证据源；不同人确实独立运行且报告环境的测试才可能增加独立验证。相同观点不自动证明串联，信息独特也不自动意味着独立。
- 无法查明来源关系时标为未确认，不编造依赖链，不机械累加“多少家都这样说”。可按需记录“本链接 → 原始演示/测试/公告”；多个独立实验室/环境是否适用于当前问题仍由模型判断。

## 评论和多模态结论

评论可帮助定位复现步骤、报错、硬件/软件版本、失败条件、反例和纠错。点赞和热门rank只是曝光/认可线索；第一手自述仍是自述，需核实的关键反例也不能仅凭一条评论定论。先用有限预算筛选高信息内容，仅在确有缺口时扩大评论、最新排序或楼中楼，不将可见评论比例外推为整体用户比例。

音视频的核实要对应具体主张：字幕能说明讲了什么；实际操作画面可能证明步骤/界面，音频样本可能支持听感观察，评论可能揭示适用条件，均不自动证明其他模态或普遍效果。需要比较音频效果时关注源素材、响度、压缩/后期和播放条件，必要时寻找可对照样本；无需因此启动完整音频工程或强制下载。

先核实当前工具实际支持的模态。本网关原内容接口提供元数据、已校验CC、评论和弹幕；0.3.0另有可选视觉工具，是否可用以当前get_capabilities为准，**不因此具有音频试听能力**。可按用户范围使用当前环境其他真实可用的查看/试听工具；不可用则记录“画面未读取/音频未试听”，改找可获得证据或保留结论边界。原有BV/分P/CID、语言与时长校验继续适用；视觉工具按有限分段读取，不自动下载完整视频、音频或执行ASR。画面已看不等于亲自操作，听过样本不等于完成控制实验；内容校验通过也不等于其中声明属实。

## 冲突、追溯与停止

先看冲突是否来自日期、版本、配置、素材、测试口径或适用人群不同，再决定是否定向补搜。仍不确定时说明哪项证据支持哪种范围、什么尚未验证；不靠播放量、点赞、多数转载或营销标签强行裁决。

关键结论按需要保留：声明及适用条件 → 实际原来源链接与定位（时间戳/分P/评论ID等已有标识）→ 发布与采集时间（未知则标明，不能用抓取时间代替发布）→ 重要判断依据/来源关系 → 验证状态与缺口。可复用MCP已有归属、采集时间和coverage；研究判断写入回答或用户请求的研究记录，**不声称后端已新增可信度字段、来源图谱或自动归档推理**。引用二手来源时注明依赖，未读原文不能写成已核验原文。

充分且相互独立的证据已支持当前范围时停止追加；若只剩重复材料或成本高于信息收益，可停止并保留不确定性。遇到重要新反例才考虑重开该判断。遵守既有风控、请求及Token预算，核实不是绕过限制或无限搜索的理由。
